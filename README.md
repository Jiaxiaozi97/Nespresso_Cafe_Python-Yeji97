☕ Nespresso Café Management System
A Python-based café management system inspired by Nespresso cafés.
This project helps manage customers, orders, memberships, billing, discounts, and order history using file handling and Object-Oriented Programming (OOP).

✨ Features

👤 Customer Registration & Login
☕ Café Menu Management
🛒 Place Orders
💳 Membership System
🎁 Automatic Discount for Members
🧾 Bill Generation
💰 Track Total Money Spent
📂 Store Customer Data in TXT Files
📜 Order History Saving
🧠 Built using OOP Concepts


🛠 Technologies Used

Python
File Handling (.txt files)
Object-Oriented Programming (OOP)

🚀 How to Run

Clone the repository:
* git clone https://github.com/your-username/nespresso-cafe.git

Open the project folder:
cd nespresso-cafe

Run the program:
python main.py
